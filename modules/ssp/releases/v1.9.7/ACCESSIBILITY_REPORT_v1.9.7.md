# Accessibility Report — SSP v1.9.7

The workspace provides named primary and secondary navigation, meaningful headings and breadcrumbs, labeled scope/module/search/sort controls, an announced live region, visible focus, focus trapping while open, focus restoration on details/workspace close, and non-color local-governance qualifications.

Desktop light, desktop dark, and 768px constrained layouts passed browser checks. Browser Back closes the local workspace without leaving the runtime. Portfolio print suppresses navigation chrome.

Automated evidence does not replace representative human assistive-technology testing. The repository draft PR also runs the shared axe-core gate.
