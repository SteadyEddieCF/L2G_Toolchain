# CMMC L2 Gap Workshop Tool Roadmap after v78

## v78 — Contract-safe Reporting and SSP/Workbook Alignment — current draft candidate

- Adds advisor-appropriate accepted-only reporting with source linkage, request/provider-follow-up status, due dates, and linked action/blocker identifiers.
- Adds narrower client-safe reporting that removes advisor-only fields, source fingerprints, sensitive values, and local paths.
- Adds deterministic HTML, Markdown, JSON, CSV, and print-friendly reporting snapshots.
- Adds optional additive helper snapshots to the existing Workbook Handoff 1.7 and SSP Handoff 1.0 packages.
- Preserves downstream reviewer control, stable contracts, v77 record identities, and Workshop authority.
- Does not claim Builder/Merger or SSP consumption and does not introduce a review/delivery profile.

## v79 — Full McFirecoal Toolchain Regression — committed next release

- Execute the complete named six-tool chain with the registered McFirecoal v1.2.0 three-part fixture.
- Validate direct and return routes, source lineage, ownership/request/follow-up identity, optional helper handling, workbook return, SSP round trip, and Control Center read-only recognition.
- Publish a named exact-version suite snapshot only after every direct route passes.

## v80 — Stabilization and Contract Freeze — committed

- Complete full 110-practice and 320-objective regression.
- Validate accessibility, constrained viewport, print, light/dark, performance, recovery, migration, and deterministic exports.
- Freeze a production reporting/helper contract only if actual downstream consumption requires it and governance separately approves it.

## v81 — Contract and RACI Mapping — proposed, not committed

Structured import and advisor review for contracts, SOWs, SLAs, RACI matrices, and provider control matrices with source traceability and explicit acceptance.

## v82 — Provider Evidence Request Pack Generator — proposed, not committed

Generate provider-specific request packs only from accepted Workshop records, separating platform, configuration, operational, and shared evidence.

## v83 — Reusable Service Profile Library — proposed, not committed

Local versioned service templates that always require engagement-specific validation before use.

## v84 — Portable Suite Readiness — proposed, not committed

Optimize state, startup, export size, relative paths, manifests, hash verification, update/rollback, and no-install behavior.

## v85 — Production Suite Snapshot and Long-Term Support — proposed, not committed

Define supported exact-version combinations, migration policy, regression cadence, and long-term support rules.

## v86 — Evidence Ownership Maintenance Governance — proposed, not committed

Add source-review records, retirement/replacement rules, and age thresholds without converting administrative status into evidence sufficiency.

## Continuing boundaries

- Workshop remains authoritative for facilitated practice conclusions, evidence review and requests, provider/responsibility discussion, provider follow-up, gaps, actions, blockers, and accepted evidence-ownership records.
- Workbook results remain reviewer-controlled; SSP content and SSP review history remain SSP-controlled.
- Builder/Merger remains authoritative for document/workbook assembly and final client-delivery packages.
- Control Center remains read-only compatibility, routing, and observability.
- No automatic Met/Not Met, evidence sufficiency, readiness, risk, compliance, certification, assessment conclusion, or scoring.
- All runtime behavior remains local/offline with no telemetry or remote runtime dependency.
- Stable package identities change only through separately approved contract releases.
