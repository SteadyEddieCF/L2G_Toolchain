## Authority boundary

- Scope owns boundaries, systems, assets, providers, services, locations, enclaves, data flows, assumptions, unknowns, dependencies, diagrams, decisions, candidates, import receipts, projections, and factual next work.
- Other domains and Scoper packages may publish context/candidates but cannot directly mutate accepted Scope state.
- Objects describe the environment. Accepted Scope decisions establish accepted category, disposition, relationship, implementation location, responsibility, flow treatment, and approved diagram-representation state.
- Asset category, Scope disposition, boundary relationship, implementation location, responsibility, lifecycle, operational, review, visibility, currency, and decision state remain separate dimensions.
- Diagrams are exact-version representations and not authority sources.
- Client projections are built before counts, search, render, inspector, differences, history, focus, live regions, diagram alternatives, and accessibility-tree construction.
