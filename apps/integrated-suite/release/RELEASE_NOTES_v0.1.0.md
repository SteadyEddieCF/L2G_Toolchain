# L2G Integrated Suite Foundation v0.1.0

## Purpose

Establish the smallest safe integrated application foundation while preserving every current standalone module, current pointer, stable contract, and historical suite snapshot.

## User-visible foundation

- One compact shared shell with Overview, Pre-Engagement, Evidence, Scope, Practice Review, SSP, Deliverables, and Reviews & Actions.
- Advisor, Client, and Reviewer presentation profiles with a persistent qualification that profiles are not security roles.
- Local engagement identity and participant editing using synthetic data only.
- Human-readable Undo and Redo.
- Append-oriented history, named checkpoints, and explicit restoration events.
- New, Open, Save, Save As, verified backup, and browser recovery flows with truthful save-state language.
- Read-only compatibility catalog for current legacy contracts.

## Security and integrity

- Single-file runtime with hashed inline script/style CSP and `connect-src 'none'`.
- No remote runtime assets, APIs, telemetry, analytics, fonts, frames, or forms.
- Deterministic store-only `.l2g` ZIP container.
- Duplicate archive paths, traversal paths, compressed entries, nested archives, CRC failures, oversized entries, and unsupported path sets are rejected before governed-state mutation.
- Governed JSON is parsed with explicit duplicate-key rejection.
- Project payloads are covered by SHA-256 integrity records.

## Release engineering

- Locked TypeScript 5.8.3 build dependency.
- Deterministic HTML identity.
- Release SHA-256 manifest.
- SPDX 2.3 SBOM.
- Synthetic valid and adversarial project fixtures.
- Dedicated Linux and Windows CI workflow.
