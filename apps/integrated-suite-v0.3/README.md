# L2G Integrated Suite v0.3.0 — Engagement Spine

This additive source tree implements the accepted ADR-0008 engagement authority and preserves the v0.2 encrypted-project safety foundation.

## Build and test

```bash
npm ci
npm test
```

The deterministic build produces one portable HTML file under `dist/` and a release package under `releases/v0.3.0/`.

## Included

- canonical `l2g_engagement_v1` authority in `domains/engagement.json`;
- explicit candidate Accept, Modify, Reject, and Supersede commands;
- deterministic v0.2 and v0.1 engagement migration;
- profile-filtered immutable workspace projections;
- factual next-work calculation without readiness or compliance scoring;
- participants, organizations, assumptions, decisions, questions, constraints, milestones, and blockers;
- encrypted portable persistence, encrypted recovery, history, checkpoints, Undo, and Redo;
- Advisor, Client, and Reviewer presentation profiles.

## Qualification

Synthetic data only. Encryption and the richer engagement model do not authorize production, client, FCI, or CUI use. Presentation profiles are not security roles. This release does not establish readiness, compliance, certification, scoring, evidence sufficiency, risk, or Met/Not Met conclusions.
