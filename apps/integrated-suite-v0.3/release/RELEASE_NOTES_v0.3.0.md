# L2G Integrated Suite v0.3.0 — Engagement Spine

## Included

- canonical `l2g_engagement_v1` authority for engagement identity and planning context;
- participants, organizations, assumptions, decisions, open questions, constraints, milestones, blockers, and candidates;
- explicit candidate Accept, Modify, Reject, and Supersede commands with rationale and preserved provenance;
- Advisor, Client, and Reviewer projections filtered before rendering and delivered as frozen copies;
- deterministic factual next-work rules without readiness or compliance scoring;
- deterministic migration of valid v0.2 encrypted and v0.1 synthetic projects into the v0.3 engagement schema;
- migration checkpoint, append-oriented history, Undo, Redo, checkpoints, encrypted saves, encrypted recovery, and project locking;
- eight-workspace shell with read-only engagement context across future domain vertical slices;
- restrictive CSP, zero runtime network dependencies, deterministic application build, synthetic fixtures, and Linux/Windows `file://` validation.

## Important limitations

This release remains synthetic-only. It does not authorize production, client, FCI, or CUI data. Presentation profiles are not security roles and do not protect a complete project file from its holder. The release does not migrate Evidence, Scope, Practice Review, SSP, or Deliverables authority and does not establish readiness, compliance, certification, scoring, evidence sufficiency, risk, or Met/Not Met conclusions.
